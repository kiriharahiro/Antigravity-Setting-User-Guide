## 💡 アプリ（index.html）の利用方法

1. [index.html](index.html) をエクスプローラーからダブルクリックしてブラウザで開きます。
2. 検索バーに任意のキーワード（例：`afterDelay`, `GEMINI.md`, `別室相談`, `diff`, `画像` など）を入力します。
3. **キーボードスクロール対応**:
   - `↑` / `↓`（上下矢印キー）：左ウィンドゥ（記事一覧）を**小さくスクロール**（約50pxずつ）
   - `PageUp` / `PageDown`：左ウィンドゥ（記事一覧）を**1ページ分スクロール**（約200px・カード約2枚分）
   - `Home` / `End`：一覧の最上部・最下部へジャンプ
   - `/` キー：検索ボックスへ素早くフォーカス
4. 左側の記事一覧から気になる記事をクリックすると、右側にTipsを含む詳細情報が表示されます。
5. 「noteで記事を読む」ボタンでWeb記事へ、「Spotifyラジオを聴く」ボタンで連動する音声ポッドキャストへワンクリックでジャンプできます。
