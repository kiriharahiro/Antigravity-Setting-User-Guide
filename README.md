# 🚀 『一日一歩Antigravity』記事インデックス＆検索ビューア

タカハシノリアキさんのnoteマガジン『一日一歩Antigravity』（全36記事）を体系化・分析し、タイトルだけでは分からない実践Tipsや重要ノウハウを含めた横断検索Webアプリケーション＆インデックスリポジトリです。

🌐 **Webアプリ公開URL（GitHub Pages）**:  
[https://kiriharahiro.github.io/Antigravity-Setting-User-Guide/](https://kiriharahiro.github.io/Antigravity-Setting-User-Guide/)

---

## 🌟 主な機能と特徴

1. **リアルタイム横断検索**:
   - 記事タイトルだけでなく、「実践Tips」「概要・要約」「目次・見出し」「キーワードタグ」など、全項目を対象に一瞬でインクリメンタル検索。複数単語のスペース区切りAND検索にも対応。
2. **実践Tips・重要ノウハウの抽出**:
   - 各記事から「タイトルではわからない実践知・設定値・裏ワザ」をフォーカス表示。
3. **キーボード操作対応（高速ブラウジング）**:
   - `↑` / `↓`：記事一覧を小さくスクロール（約50px）
   - `PageUp` / `PageDown`：1ページ分（約200px）を大きくスクロール（長押しで高速連続送り）
   - `Home` / `End`：一覧の先頭・末尾へ瞬時ジャンプ
   - `/` キー：検索バーへ素早くフォーカス
4. **外部リンク連携**:
   - 各記事の **note公式記事** へのダイレクトリンク
   - 連動ポッドキャスト **Spotifyラジオ（いつも隣におしごとラジオ）** への直接リンク
5. **ワンクリック共有・コピー機能**:
   - タイトル・URL・概要・実践Tipsを綺麗に整形してクリップボードにコピー可能。
